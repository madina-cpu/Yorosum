# Label & Claims Compliance Review — YOROSUM Glow Peptide

**Classification:** 기타가공품 (일반식품). Not 기능성표시식품 or 건강기능식품 (per 품목제조보고서).
**What that means:** in Korea this product may state **what it contains**, never **what it does to the body**. Pre-review isn't required, but every 식품표시광고법 제8조 prohibition still applies in full, and liability falls on the brand owner (신라글로벌트레이딩), not CNS Pharm.

> This is a compliance screen, not legal advice. For the flagged items, get a written opinion from 한국식품산업협회 (KFIA) or the local 식약처 office before the next print run or ad campaign.

## 1. Carton review

| # | Text on carton | Verdict | Reason | Action |
|---|---|---|---|---|
| 1 | **"하루 한 포로 채우는 이너뷰티 루틴"** (side panel) | 🔴 **FLAG** (제8조① 3호 건강기능식품 오인; 5호 소비자 기만 risk) | "이너뷰티" (inner beauty) implies a skin or beauty effect from eating the product. On a general food this reads as a health-functional claim. It's one of the flag words regulators list for collagen products. | **Don't repeat it** in any ad, detail page, keyword or B2B document. Ask KFIA or 식약처 for an opinion; if they agree, fix it on the **next print run** (or sticker over it on remaining stock). Compliant replacement: **"하루 한 포, 간편한 콜라겐 데일리 스틱"** |
| 2 | Product name **"글로우 펩타이드 / GLOW PEPTIDE"** | 🟡 **BORDERLINE** (3호/5호) | "Glow" can be read as implying a skin-radiance effect. It's a registered product name, which carries some weight, but names are judged as advertising too. Combined with "이너뷰티" the overall impression gets stronger. | Keep the name for now, but **never pair it with skin imagery or beauty-effect wording**. Raise it in the same KFIA consultation. |
| 3 | "저분자 생선콜라겐 데일리 스틱" | ✅ PASS | Factual description | Evidence: raw-material spec ("저분자 피쉬콜라겐", ATHOS) |
| 4 | "생선콜라겐 2,000mg" | ✅ PASS | Composition | Evidence: 품목제조보고서 (66.6667% × 3 g) |
| 5 | "비타민 C 100mg" | ✅ PASS | Composition, matches nutrition panel | Evidence: COA (125.33 mg, spec 80–150 mg) |
| 6 | "300Da 저분자 생선콜라겐의 평균분자량" | ✅ PASS **if** evidence held | Factual, but a measured number needs proof | **Get the molecular-weight test report** from ATHOS / 예르바코리아 and keep it on file (MFDS can demand it within 15 days) |
| 7 | "엘라스틴가수분해물 0.1% / 대나무수액추출분말 1% / 복숭아맛분말 10%" | ✅ PASS | Composition with honest percentages | — |
| 8 | Peach illustration | ✅ PASS | Flavour imagery, no skin or body imagery | Keep skin photos away from ingredient numbers in all ads |

**Penalty exposure if item 1 is judged a 3호 violation:** up to 10 years' imprisonment or a ₩100M fine (제26조), plus possible business suspension. Enforcement usually starts with online ads and keywords, not cartons, so **the urgent action is keeping "이너뷰티" out of every online listing, search tag and ad.**

## 3. Central Asia label adaptation (for the registration agent)

| Item | Note |
|---|---|
| Allergens | Milk must be declared; the "may contain" list (incl. **pork**) must be translated. Expect questions from Muslim-majority buyers, so prepare an answer (the product contains no pork ingredient; the cross-contact statement is precautionary) |
| Sweeteners | Xylitol, stevia (steviol glycosides) and sucralose are permitted in the EAEU with E-numbers (E967, E960, E955); the agent should confirm levels |
| Ethanol | Present as a carrier in the flavour preparation. Usually trace-level, but relevant for halal certification and for some buyers |
| Category | Agent to advise: **БАД** (needs СГР; can carry approved functional wording) or **ordinary food / drink mix** (EAC declaration only; cheaper and faster, composition-only claims). See `02-regulatory-checklist.md` |
| Vitamin C 100 mg | Within typical EAEU limits for supplements; the agent should confirm against the Uniform Sanitary Requirements |
